# Portfolio Website

This is a clean, modern portfolio website template for showcasing apps and products.

## Run locally

Open the project in a browser using any static file server, or run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customize it

- Update the text in `index.html`
- Replace placeholder app names in `script.js`
- Adjust colors and layout in `styles.css`
